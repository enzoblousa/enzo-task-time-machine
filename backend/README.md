### Installation 🔧

1.  Clone this repository.

    ```shell
    git clone git@github.com:enzoblousa/enzo-task-time-machine.git
    cd enzo-task-time-machine/backend
    ```

2.  Install this code base.

    ```shell
    make install
    ```
